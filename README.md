# GLYPH ASCII Studio

安装：`npm ci`

本地启动：`npm run dev`

Docker 启动：`docker compose up --build`，访问 http://localhost:18018。

## 盲文点阵制版

顶部切换「盲文点阵制版」模式：裁剪图按真实 2×4 点位组合成盲文字符，可在放大点阵上逐点修整（手改锚定原图采样位置，密度变化后落点冲突会显式标记、不随机覆盖，冲突未解决时禁止导出）。奇数宽度、末尾不足一组与透明区域均明确补齐。制版模式可在「保留轮廓 / 保留灰阶」间选择并对比点位损失；屏幕预览借颜色表达灰度，印刷预览与 SVG 导出使用固定物理点距（毫米），纸张不足时按整单元分页。盲文文本、彩色画面与印刷分页均来自同一份确认点阵。

逻辑冒烟测试：`npm test`
